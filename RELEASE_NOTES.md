# LyxBridgeCodeX v0.3.0 (unreleased)

Experimental LyX source overlay and Codex plugin for macOS Apple Silicon. Source is available in the repository; packaged releases remain on hold while testing continues.

- Real LyX 2.5.3 editing in a Codex side panel, including editable formulas, native undo, and familiar shortcuts.
- Versioned native builds support upgrading from 2.4.1 without interrupting open sessions. LyX 2.4 files import normally; saves use format 643. Private preferences prefer the 2.5 profile, with a 2.4 fallback.
- Pure LaTeX pseudocode templates in the environment chooser, native rendered previews, and a complete PDF tutorial in `demo/`.
- Native recovery snapshots run every minute while changes are unsaved; use Save to update the main `.lyx` file. A newer snapshot opens an interactive startup prompt to load the backup, load the original, or cancel. Repeated opens reuse the pending prompt, and recovery never silently overwrites the original file.
- Environment lists and native menus fit the editor panel, with scrolling for long lists and menu reflow after resizing.
- The hidden keyboard input no longer changes the browser's scrollable area when the LyX caret moves offscreen.
- macOS-inspired flat chrome and slim rounded scrollbars keep native pointer, wheel, and keyboard behavior without requiring Cocoa windows.
- Narrow panels fit the native frame without phantom browser scrollbars; resizing preserves pointer and input-method coordinates, and oversized dialogs remain reachable.
- Connection errors show a persistent Retry control and pause new editing input until the session responds. Retry reads the existing session and waits for any frame check already in progress. Missing initial file context and startup errors now have explicit feedback.
- Only a structured, confirmed native-process exit exposes **Reopen editor**. It uses the last verified file path, including Save As, preserves the native recovery prompt, and never replays queued edits. Historical chat selections and the draft remain unchanged; current selection indicators reset.
- Reopening a known document checks its live session first; unrelated unresponsive sessions no longer delay that reopen. Fresh-engine readiness shares a 40-second startup deadline while ordinary RPCs retain their 15-second limit. Private profile overrides leave desktop preferences unchanged and provide a plain startup background without the welcome banner or captured splash windows. Verified TeX configuration can be reused for up to five minutes within the broker process, with engine/profile/environment invalidation and normal configuration as the fallback. A disposable local test measured 8,876 ms cold and 399 ms warm; these are not guaranteed startup times. See `docs/editor-ux.md`.
- Faster scrolling through lossless PNG encoding and a combined input/state MCP request. Native changed-frame median latency fell by about 41% in the second local comparison; complete Codex input-to-display latency remains unmeasured. See `docs/scroll-performance.md`.
- Browser-confirmed printable keys complete native shortcut sequences, including Control-P followed by Space or a letter; the environment chooser supports navigation, acceptance and cancellation.
- Clicking outside a native menu dismisses its full submenu chain without activating the underlying document. Popup routing follows queued input order and retains menu-bar switching and pointer cancellation.
- Command-? (Command-Shift-/) opens the native Help menu in the embedded macOS editor; Escape and outside clicks dismiss it without changing the document selection.
- **add to chat** attaches only selection context. No text is inserted into the composer and no message is automatically sent.
- **add to chat** captures a compact native selection snapshot. Codex can edit it directly after the cursor moves, with exact document revision checks, one-step undo and no automatic save. Snapshot edits use one RPC and return a compact receipt; identical retries cannot apply twice. Snapshots last 30 minutes with the latest 32 retained per process. Existing engines and tools retain the legacy workflow until refreshed.
- Portable local configuration, Qt-prefix detection, support for an existing pinned LyX source checkout, a self-contained example, build scripts, compact overlay archives, and SHA-256 checksums.

**Tested Codex desktop: 26.1016.51333 (build 21161).** Plugin-installation CLI: 0.163.0-alpha.11. Native environment: macOS 26.7.1 arm64, Qt 5.15.2. These identify verified environments; other versions and platforms are not guaranteed.

Clone the repository and follow its README. Node/npm, Qt 5.15 development files, CMake, compiler tooling, and LyX's build dependencies are required. Provide an official LyX 2.5.3 Git checkout at the pinned commit via `LYX_SOURCE_DIR`, or let the build fetch it. Web resources and the native engine are built locally. Upstream LyX source, compiled engines, Qt, node_modules, and generated bundles are excluded. This is not a signed installer or a self-contained application binary.

Known limits include Fusion-based widgets rather than full Cocoa styling, keyboard-only system paste in the tested host, no native file dropping, and incomplete OS input-method/trackpad coverage. Host file opening requires the target chat to be displayed; its `queued` acknowledgement alone confirms neither success nor failure. Disposable native and local browser tests do not establish that the actual Codex panel opened. Broker loss does not confirm native-child exit: ordinary editor requests and Reopen editor never start a replacement broker or recover orphaned sessions. Native edits do not automatically save. See `docs/compatibility.md` and `docs/editor-ux.md` for details.
